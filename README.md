# Система учета рабочего времени, геозонирования и почасового табелирования

Мультиплатформенная корпоративная система контроля посещаемости сотрудников на объектах с двойным фактором аутентификации (GPS + динамический QR-код). Система ведет детальный почасовой учет на основе отметок начала и окончания смен, автоматически формируя для бухгалтерии итоговый табель-шахматку в формате Excel (.xlsx).

Проект разработан полностью на языке Python и оптимизирован для работы в изолированных виртуальных окружениях (включая экосистему Python 3.14+).

## Основные возможности системы

* **Централизованное администрирование**: Исключена саморегистрация сотрудников. Учетные записи (ФИО, Должность) вносятся администратором напрямую в базу данных.
* **Почасовой учет времени (Вход / Выход)**: Система фиксирует не просто факт прихода, а конкретное действие сотрудника: `IN` (Начало смены) или `OUT` (Завершение смены). Сервер рассчитывает точную длительность работы за каждые сутки.
* **Двойной контроль присутствия (Анти-фрод)**:
  * **Геофенсинг (GPS)**: Сервер рассчитывает расстояние от смартфона до объекта по формуле гаверсинусов. Чекин блокируется, если сотрудник находится дальше 50 метров от рабочей точки.
  * **Динамический QR-код (TOTP)**: Защита от фотофиксации и пересылки кодов в чатах. Сервер генерирует уникальный 6-значный хэш, который обновляется каждые 30 секунд.
* **Автоматический аудит**: Все запросы (включая заблокированные из-за неверного GPS или устаревшего QR) сохраняются в базу данных для контроля со стороны руководства.
* **Бухгалтерский табель-шахматка**: Автоматическая генерация классического плоского табеля за текущий месяц. По горизонтали выстраивается календарная сетка (от 1 до 31 числа) с отработанными часами в ячейках. В конце каждой строки и внизу таблицы встроены формулы автоматического подсчета сумм часов и дней.

## Архитектура и стек технологий

* **Корневой язык**: Python
* **Бэкенд-сервер**: FastAPI + Uvicorn
* **База данных**: SQLite (для локальной разработки) / PostgreSQL (промышленный стандарт)
* **Драйвер БД и ORM**: SQLAlchemy 2.0 + Psycopg 3
* **Мобильное приложение (UI)**: Flet (Flutter для Python) + Requests
* **Генерация отчетов**: OpenPyXL

## Инструкция по локальному запуску

Для работы системы требуются два параллельно запущенных процесса: сервер API и клиентское приложение.

### Подготовка окружения

1. Перейдите в корневую папку проекта:
   ```bash
   cd time_tracker_app
   ```

2. Убедитесь, что виртуальное окружение активировано:
   * **Windows**: `.venv\Scripts\Activate.ps1`
   * **Linux/macOS**: `source .venv/bin/activate`

3. Сделайте гибкую установку актуальных пакетов:
   ```bash
   # Перейдите в папку сервера и установите пакеты
   cd server
   ..\.venv\Scripts\python.exe -m pip install -r requirements.txt

   # Перейдите в папку мобильного приложения и установите пакеты
   cd ../mobile
   ..\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

### Шаг 1: Запуск сервера Бэкенда

1. Перейдите в папку сервера:
   ```bash
   cd server
   ```
2. Запустите сервер FastAPI:
   ```bash
   ..\.venv\Scripts\uvicorn.exe main:app --reload
   ```
3. Сервер успешно запущен, если в консоли отобразилась строка: `Application startup complete.`

*При первом старте сервер автоматически генерирует файл базы данных `sql_app.db` внутри папки `server/`.*

### Шаг 2: Наполнение базы тестовыми данными

Перед началом чекинов необходимо внести сотрудников в базу данных:
1. Откройте веб-браузер и перейдите по адресу: `http://127.0.0.1:8000/docs`
2. Найдите в списке зеленый эндпоинт `POST /api/admin/seed_test_data`.
3. Нажмите кнопку **Try it out**, затем нажмите синюю кнопку **Execute**. 
4. Сервер сгенерирует 4 профиля реальных должностей (Иванов И. И., Петров П. Р. и др.).

### Шаг 3: Запуск мобильного приложения

1. Откройте второй (новый) терминал и перейдите в папку мобильного приложения:
   ```bash
   cd mobile
   ```
2. Запустите симулятор мобильного интерфейса:
   ```bash
   ..\.venv\Scripts\flet.exe run main.py
   ```

## Сценарий сквозного тестирования

1. **Получение одноразового QR**: Откройте в браузере страницу симуляции офисного экрана: `http://127.0.0.1:8000/api/get_office_qr`. Скопируйте текущие 6 цифр из поля `current_qr`.
2. **Имитация работы (Вход/Выход)**: В Swagger (`/docs`) откройте эндпоинт `POST /api/checkin`. 
   * Передайте `user_id: 1`, валидный GPS, скопированный код и `action_type: IN` (утренний приход). Нажмите **Execute**.
   * Повторите запрос через некоторое время, указав `action_type: OUT` (вечерний уход).
3. **Выгрузка шахматки для бухгалтерии**: В Swagger найдите синий эндпоинт `GET /api/admin/export_tabel`. Нажмите **Try it out** -> **Execute** -> **Download file**. Скачанный файл будет содержать итоговую шахматку по дням месяца с автоматическими суммами.
