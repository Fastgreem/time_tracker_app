# Система учета рабочего времени, геозонирования и почасового табелирования с Веб-Админкой

Мультиплатформенная корпоративная система контроля посещаемости сотрудников на объектах с двойным фактором аутентификации (GPS + динамический QR-код). Система ведет детальный почасовой учет на основе отметок начала (IN) и окончания (OUT) смен, предоставляет полноценный веб-интерфейс администратора для мониторинга сотрудников и управления персоналом, а также автоматически формирует для бухгалтерии итоговый табель-шахматку в формате Excel (.xlsx).

Проект разработан полностью на языке Python и оптимизирован для работы на стабильной промышленной версии **Python 3.12**.

## Основные возможности системы

* **Полноценный Веб-интерфейс Администратора**:
  * **📊 Мониторинг смен (Дашборд)**: Отображает в режиме реального времени, кто из сотрудников сейчас находится на объекте (горит зеленый статус `🟢 НА РАБОТЕ`), их последнее действие (`IN`/`OUT`) и точное время отметки.
  * **👥 Управление персоналом**: Централизованное добавление сотрудников, быстрое изменение должностей прямо в ячейках таблицы и безвозвратное удаление учетных записей из базы данных. Саморегистрация сотрудников заблокирована ради безопасности.
* **Почасовой учет времени (Вход / Выход)**: Система фиксирует конкретное действие сотрудника: `IN` (Начало смены) или `OUT` (Завершение смены). Сервер рассчитывает точную длительность работы за каждые сутки.
* **Двойной контроль присутствия (Анти-фрод)**:
  * **Геофенсинг (GPS)**: Сервер рассчитывает расстояние от смартфона до объекта по формуле гаверсинусов. Чекин блокируется, если сотрудник находится дальше 50 метров от рабочей точки.
  * **Динамический QR-код (TOTP)**: Защита от фотофиксации и пересылки кодов в чатах. Сервер генерирует уникальный 6-значный хэш, который обновляется каждые 30 секунд.
* **Бухгалтерский табель-шахматка**: Автоматическая генерация классического плоского табеля за текущий месяц. По горизонтали выстраивается календарная сетка (от 1 до 31 числа) с отработанными часами в ячейках. В конце каждой строки и внизу таблицы встроены формулы автоматического подсчета сумм часов и дней.

## Архитектура и стек технологий

* **Корневой язык**: Python 3.12
* **Бэкенд-сервер и Веб-движок**: FastAPI + Uvicorn + Шаблонизатор Jinja2 (HTML5 + Bootstrap 5)
* **База данных**: SQLite (для локальной разработки) / PostgreSQL (промышленный стандарт)
* **Драйвер БД и ORM**: SQLAlchemy 2.0 + Psycopg 3
* **Мобильное приложение (UI)**: Flet (Flutter для Python) + Requests
* **Генерация и разметка отчетов**: OpenPyXL
* **Аналитический движок**: Pandas

## Инструкция по локальному запуску (Абсолютные пути Windows)

Для работы системы требуются два параллельно запущенных процесса: сервер API и симулятор приложения.

### Шаг 1: Запуск сервера Бэкенда и Веб-Админки

1. Откройте первый терминал PowerShell в VS Code.
2. Запустите сервер FastAPI, используя абсолютные пути проекта:
   ```bash
   C:\Users\username\projects\python\time_tracker_app\.venv\Scripts\uvicorn.exe --app-dir C:\Users\username\projects\python\time_tracker_app\server main:app --reload
   ```
3. Сервер успешно запущен, если в консоли отобразилась строка: `Application startup complete. Uvicorn running on http://127.0.0.1:8000`.

*При первом старте сервер автоматически генерирует чистый файл базы данных `sql_app.db` внутри папки `server/`.*

### Шаг 2: Наполнение базы данных и работа с Админкой

1. Откройте ваш браузер и перейдите по адресу главного сайта: `http://127.0.0.1:8000/admin/dashboard`
2. Вы автоматически перенаправитесь в панель мониторинга смен (`/admin/dashboard`).
3. Перейдите во вкладку меню **«Сотрудники»** (`/admin/users`).
4. В левой форме введите ФИО и должность, нажмите **«Сохранить в базу»**. Сотрудник мгновенно появится в базе данных с уникальным `ID` и возможностью изменения роли или удаления.

### Шаг 3: Запуск мобильного приложения Flet

1. Откройте второй (новый) терминал PowerShell в VS Code.
2. Запустите симулятор мобильного интерфейса:
   ```bash
   C:\Users\username\projects\python\time_tracker_app\.venv\Scripts\python.exe C:\Users\username\projects\python\time_tracker_app\mobile\main.py
   ```
3. На экране вашего ПК откроется независимое окно приложения.

## Сценарий сквозного тестирования

1. **Получение одноразового QR**: Откройте в браузере страницу симуляции офисного экрана: `http://127.0.0api/get_office_qr`. Скопируйте текущие 6 цифр из поля `current_qr`.
2. **Имитация работы (Вход/Выход)**: В Swagger (`http://127.0.0docs`) откройте эндпоинт `POST /api/checkin`. 
   * Передайте `user_id: 1` (созданный вами сотрудник), валидный GPS, скопированный код и `action_type: IN` (утренний приход). Нажмите **Execute**.
   * На главной веб-странице админки статус сотрудника мгновенно изменится на **🟢 НА РАБОТЕ**.
   * Повторите запрос через некоторое время, указав `action_type: OUT` (вечерний уход). Статус изменится на **⚪ Вне объекта**.
3. **Выгрузка шахматки для бухгалтерии**: Нажмите на зеленую кнопку **«Скачать Табель (Excel)»** в шапке веб-админки. Скачанный файл будет содержать официальную шахматку по дням месяца с автоматическим расчетом отработанных часов за смену и формулами сумм `SUM`.
