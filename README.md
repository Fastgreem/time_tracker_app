# Система учета рабочего времени, геозонирования и расчета КТУ

Мультиплатформенная корпоративная система контроля посещаемости сотрудников с двойным фактором аутентификации (GPS + динамический QR-код), автоматическим расчетом Коэффициента трудового участия (КТУ) и выгрузкой структурированных отчетов в формате Excel для бухгалтерии.

Проект разработан полностью на языке Python и оптимизирован для работы в изолированных виртуальных окружениях (включая экосистему Python 3.14+).

## Основные возможности системы

* **Централизованное администрирование**: Исключена саморегистрация сотрудников. Учетные записи (ФИО, Роль, Должность) вносятся администратором напрямую в базу данных.
* **Двойной контроль присутствия (Анти-фрод)**:
  * **Геофенсинг (GPS)**: Сервер рассчитывает расстояние от смартфона до офиса по формуле гаверсинусов. Чекин блокируется, если сотрудник находится дальше 50 метров.
  * **Динамический QR-код (TOTP)**: Защита от фотофиксации и пересылки кодов. Сервер генерирует уникальный 6-значный хэш, который обновляется каждые 30 секунд.
* **Логирование попыток обмана**: Все запросы (включая заблокированные из-за неверного GPS или устаревшего QR) сохраняются в базу данных для последующего аудита руководством.
* **Бухгалтерская отчетность**: Автоматическая агрегация логов времени, расчет активности персонала и КТУ за выбранный период с экспортом в регламентированный Excel-файл (.xlsx).
* **Кроссплатформенный клиент**: Интерфейс мобильного приложения написан на фреймворке Flet (экосистема Flutter) и готов к компиляции под Android и iOS.

## Архитектура и стек технологий

* **Корневой язык**: Python
* **Бэкенд-сервер**: FastAPI + Uvicorn
* **База данных**: SQLite (для локальной разработки) / PostgreSQL (промышленный стандарт, поддерживаемый ORM)
* **Драйвер БД и ORM**: SQLAlchemy 2.0 + Psycopg 3
* **Мобильное приложение (UI)**: Flet (Flutter для Python) + Requests
* **Генерация отчетов**: OpenPyXL

## Инструкция по локальному запуску

Для работы системы требуются два параллельно запущенных процесса: сервер API и клиентское приложение.

### Подготовка окружения

1. Клонируйте репозиторий или перейдите в корневую папку проекта:
   ```bash
   cd time_tracker_app
   ```

2. Убедитесь, что виртуальное окружение создано и активировано:
   * **Windows**: `.venv\Scripts\Activate.ps1`
   * **Linux/macOS**: `source .venv/bin/activate`

3. Установите необходимые зависимости для обоих компонентов системы:
   ```bash
   # Перейдите в папку сервера и установите пакеты
   cd server
   ..\.venv\Scripts\python.exe -m pip install -r requirements.txt

   # Перейдите в папку мобильного приложения и установите пакеты
   cd ../mobile
   ..\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

### Шаг 1: Запуск сервера Бэкенда

1. Откройте первый терминал и перейдите в папку сервера:
   ```bash
   cd server
   ```
2. Запустите сервер FastAPI в режиме автоматической перезагрузки:
   ```bash
   ..\.venv\Scripts\uvicorn.exe main:app --reload
   ```
3. Сервер успешно запущен, если в консоли отобразилась строка: `Application startup complete. Uvicorn running on http://127.0.0.1:8000`.

*При первом запуске сервер автоматически создаст файл локальной базы данных `sql_app.db` внутри папки `server/`.*

### Шаг 2: Наполнение базы тестовыми данными

Перед тестированием необходимо внести сотрудников в базу данных через интерактивную панель управления:
1. Откройте веб-браузер и перейдите по адресу: `http://127.0.0.1:8000/docs`
2. Найдите в списке зеленый эндпоинт `POST /api/admin/seed_test_data`.
3. Нажмите кнопку **Try it out**, затем нажмите синюю кнопку **Execute**. 
4. Сервер сгенерирует 4 тестовых профиля сотрудников (с ID от 1 до 4).

### Шаг 3: Запуск мобильного приложения

1. Откройте второй (новый) терминал и перейдите в папку мобильного приложения:
   ```bash
   cd mobile
   ```
2. Запустите симулятор мобильного интерфейса:
   ```bash
   ..\.venv\Scripts\flet.exe run main.py
   ```
3. На экране вашего ПК откроется независимое окно приложения.

## Сценарий тестирования двойного контроля

1. **Получение одноразового QR**: Откройте в браузере страницу симуляции офисного экрана: `http://127.0.0.1:8000/api/get_office_qr`. Скопируйте текущие 6 цифр из поля `current_qr`.
2. **Успешный чекин**: Введите эти 6 цифр в окно запущенного приложения Flet (по умолчанию в коде прописан валидный ID: 1 и координаты офиса). Нажмите кнопку. Система выдаст зеленый статус успешной авторизации.
3. **Проверка выгрузки Excel**: Вернитесь в браузер на страницу `http://127.0.0.1:8000/docs`. Найдите синий эндпоинт `GET /api/admin/export_tabel`. Нажмите **Try it out** -> **Execute** -> **Download file**. Скачанный файл будет содержать актуальную таблицу посещений и КТУ ваших сотрудников.
